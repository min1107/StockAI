# 🧠 AI 판단 엔진 — 설계서

종목의 매수/보유/매도를 판단하는 엔진의 **목표 설계**와 단계별 구현 계획.

## 0. 철학
- **객관(점수 엔진) + 해석(AI) 하이브리드.** 숫자로 되는 건 규칙으로 투명하게, 맥락·해석은 AI로.
- **일반인이 못 보는 전문가의 시야**를 보여준다: 시장(top-down) → 기업(bottom-up) → 가치 → 타이밍.
- **신뢰도는 진짜 측정값**(신호 일치도). 가짜 숫자 금지.

## 1. 판단 흐름
```
① 시장이 우호적인가 (매크로·시장)
   → ② 좋은 기업인가 (품질·성장)
      → ③ 가치 대비 싼가 (밸류에이션)
         → ④ 지금이 타이밍인가 (수급·기술)
            → 종합 점수 → 추천 + 신뢰도 → AI 해석
```

## 2. 6개 팩터 + 채점법

### ① 밸류에이션 — "싼가?"
- 지표: PER(섹터 평균 대비), PBR, **PEG**(PER÷이익성장률), 배당수익률, (고급) DCF 내재가치
- 채점: 섹터 대비 PER 낮고 PBR<1.5, PEG<1 → 가점 / 고평가 → 감점

### ② 품질 — "좋은 기업인가?" (버핏 핵심)
- 지표: **ROE**(≈EPS÷BPS), 영업이익률(추세), **부채비율**, 이익 꾸준함, 잉여현금흐름(FCF)
- 채점: ROE 15%+ & 저부채 & 흑자 지속 → 가점 / 적자·고부채 → 감점

### ③ 성장 — "크고 있나?"
- 지표: 매출 성장률, **이익 성장률(YoY)**, 애널리스트 추정 방향
- 채점: 두 자릿수 성장 → 가점 / 역성장 → 감점

### ④ 모멘텀·기술 — "흐름은?"
- 지표: RSI, MACD, 이동평균, **시장 대비 상대강도**, 52주 위치
- 채점: 상승추세 + 골든크로스 + 시장 아웃퍼폼 → 가점 / 과열·하락전환 → 감점

### ⑤ 수급 — "큰손이 사나?"
- 지표: 기관·외국인 순매수 (**시총 대비 % 정규화**), 공매도 비중
- 채점: 시총 대비 강한 순매수 → 가점 / 대량 이탈 → 감점

### ⑥ 심리·촉매 — "이벤트?"
- 지표: 뉴스 감성, 실적 서프라이즈, 추정 상향, 다가오는 촉매(실적일 등)
- 채점: 호재·추정 상향 → 가점 / 악재·추정 하향 → 감점

> \+ **리스크**(변동성·유동성 — 점수 보정), **매크로**(환율·금리·유가·선물 — 시장 배경)

## 3. 보수 vs 공격 — 같은 데이터, 다른 가중치
| 팩터 | 보수(가치) | 공격(모멘텀) |
|---|---|---|
| ① 밸류에이션 | **높음** | 낮음 |
| ② 품질 | **높음** | 중간 |
| ③ 성장 | 중간 | **높음** |
| ④ 모멘텀·기술 | 낮음(타이밍 보조) | **높음** |
| ⑤ 수급 | 중간 | **높음** |
| ⑥ 심리·촉매 | 중간 | 중간 |

## 4. 종합 점수 → 추천 (보유 여부 반영)
| 점수 | 미보유 | 보유 중 |
|---|---|---|
| 매우 높음 | 매수 | 추가매수 |
| 높음 | 관심(소액) | 보유 |
| 중립 | 관망 | 보유 |
| 낮음 | 관망 | 일부매도 |
| 매우 낮음 | 관망 | 전량매도 |

## 5. 신뢰도 = 일치도 + 데이터 충실도
- 팩터들이 **같은 방향**일수록 ↑, 충돌하면 ↓
- 데이터가 빠진 팩터가 많으면(예: 재무 미연동) **신뢰도 자동 하향** + "펀더멘털 미반영" 표시 (정직)

## 6. AI의 역할 (해석 레이어)
- 점수 엔진이 **뼈대(추천·신뢰도·팩터 점수)** 를 정함
- AI는 그걸 **뉴스·매크로·종목 특성으로 해석하고 사람 말로 설명** → verdict를 지어내지 않음

## 7. 함정 방지 가드
- **떨어지는 칼날**: 깊은 할인 + (수급 이탈 OR 실적 악화) → 매수 점수 깎기
- **Value trap**: 싸지만 품질(ROE·부채) 나쁘면 가치 점수 무효
- **수급 착시**: 절대 억 아닌 **시총 대비**로 정규화

## 8. 데이터 출처 & 현황
| 팩터 | 필요 데이터 | 현재 | 출처 |
|---|---|---|---|
| 밸류에이션 | PER·PBR·EPS·BPS | ✅ 있음 | KIS / Yahoo |
| 품질 | ROE·마진·부채·FCF | 🔶 일부(ROE 추정) | DART / Yahoo |
| 성장 | 매출·이익 성장 | ❌ 없음 | DART / Yahoo |
| 모멘텀·기술 | RSI·MACD·차트 | ✅ 있음 | 자체 계산 |
| 수급 | 기관·외국인 | ✅ 있음(정규화 필요) | KIS |
| 심리·촉매 | 뉴스·추정·실적일 | 🔶 뉴스만 | 네이버 / 추정데이터 |

## 9. 단계별 구현 로드맵
- **1단계** (있는 데이터): 밸류(PER/PBR/ROE) + 수급 정규화 + 칼날 가드 + 신뢰도=일치도
- **2단계** (DART/Yahoo 연동): 품질·성장 재무 추가 → 진짜 가치+품질+성장
- **3단계** (컨센서스): 추정치·촉매·상대강도·리스크 → 풀 멀티팩터

## 10. 출력 형식 (투명성)
```
추천: 매수 / 신뢰도: 82%
목표가 / 손절가 / 보유기간 / 진입전략
팩터별 점수: 밸류 +2, 품질 +2, 성장 +1, 기술 0, 수급 +2, 촉매 +1
근거 5가지 (각 팩터에서)
AI 해석 코멘트 (뉴스·맥락)
```
