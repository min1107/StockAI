# 📘 StockAI 기획·현황 문서

> 이 앱이 **무엇이고, 뭐가 만들어졌고, 뭘 더 할지**를 한눈에 보는 문서. (사람용 — 너·언니가 읽고 편집)
> 코딩 규칙·배포법 등 AI 작업 지침은 별도 `CLAUDE.md` 참고.

## 1. 한 줄 소개 & 비전
- **개인 투자자가 기관·세력·헤지펀드와 동등한 시야를 갖게 돕는 AI 투자 비서.**
- 단순 데이터 나열이 아니라, AI가 **"일반인이 못 보는 것"(맥락·해석·패턴)** 을 보여주는 게 핵심.
- **목표: ① 지금의 iOS PWA 완성도 높이기 + ② 정식 네이티브 앱(앱스토어·플레이스토어)으로 확장.**

## 2. 현재 상태 & 플랫폼
- **지금:** iOS Safari PWA (홈 화면에 추가해서 사용). 주소 `min1107.github.io/StockAI`
- **앞으로:** 같은 코드로 EAS 빌드 → **iOS/안드로이드 네이티브 앱**.
  (Expo는 웹+iOS+안드로이드를 한 코드로 뽑는 도구 → 네이티브 설정은 지우지 말고 유지)

## 3. 화면별 기능

### 🏠 홈 탭
- 시장 지수: **KOSPI / KOSDAQ** (실시간)
- 매크로 카드: **USD/KRW 환율, S&P 선물, WTI 유가, 금**
- **섹터 흐름** (업종별 등락률)
- **시장 뉴스** (네이버 뉴스 수집)
- **관심종목**: 현재가·등락률·고저·거래량 / 왼쪽 스와이프 삭제 / 종목 검색으로 추가
- 종목 탭 → 상세 화면

### 🔍 발굴 탭
- **수급 이상 감지**: 기관·외국인 집중 매수 종목(순매수 100억+)
- **배당 임박 종목**: 배당락일 30일 이내 + 배당수익률

### 💼 포트폴리오 탭
- **계좌/증권사별 분류** (계좌 생성: 증권사·별칭·색상)
- **종목 추가 4가지**: 검색(이름·티커 자동완성) / 직접입력(국내·미국 토글) / 텍스트 붙여넣기(스크린샷 OCR) / CSV 업로드
- **보유종목 카드**: 종목명·평가손익·수익률 + 보유수량·평단가·현재가·주당손익 (통화별 $/₩)
- **원화 환산 총합** (한국+미국 혼합 시 환율로 합산)
- **계좌 이동** (길게 눌러 메뉴)
- **AI 포트폴리오 진단**: 리스크 등급·종합 코멘트·매크로 영향·주목 종목·종목별 액션(추가매수/보유/매도)
- **차트**: 수익률 추이 / 보유 비중 파이 / 섹터 분산 파이(집중도 경고)
- **AI 채팅** (내 포트폴리오 기반 질문)

### ⚙️ 설정 탭
- **푸시 알림 (Web Push)** — 켜기 / 테스트
- 시장·포트폴리오 **로컬 알림 토글** — ⚠️ *웹에선 작동 안 함 (정리 대상)*
- 계정 (로그인/로그아웃), 데이터(채팅기록·캐시 삭제), 앱 정보

### 📈 종목 상세
- 차트 / 기본정보 / 52주 범위·지지저항 / **AI 분석(보수·공격)** / 지표(PER·PBR 등)
- ⚠️ *미국 주식 차트는 웹 CORS로 막힘 (미해결)*

## 4. 백엔드 (서버 — Express on Vercel)
- **AI (Groq llama-3.3-70b)**: 종목분석 / 포트폴리오 진단 / 종목추천 / AI채팅(한·미)
- **시세**: KIS(국내 현재가·차트·분봉·투자자동향·지수·섹터·검색) / Yahoo 프록시(미국 `us/quote`)
- **데이터 수집**: 매크로(15분)·뉴스(1시간)·수급(30분)·스크리닝(매일)
  - ⚠️ *무료 플랜이라 Vercel 자동 크론은 안 돌고, 앱 접속 시 lazy 수집*
- **푸시**: Web Push (VAPID, 구독 Redis 저장, 발송)
- **보안**: cron 시크릿 / rate limit / CORS allowlist / 입력 검증 / 보안 헤더

## 5. 인프라 / 기술 스택
| 영역 | 기술 |
|---|---|
| 화면 | React Native Web (Expo SDK 54), React Navigation |
| 서버 | Express on Vercel |
| 인증·DB | Supabase (RLS 적용) |
| 캐시·푸시구독·rate limit | Upstash Redis |
| AI | Groq (llama-3.3-70b) |
| 시세 | 한국투자증권 API, Yahoo Finance |
| 배포 | GitHub Pages(앱) + Vercel(서버) |

## 6. 데이터 모델 (Supabase)
- **portfolios**: user_id, stock_code, stock_name, shares, avg_price, account_id
- **accounts**: user_id, brokerage, alias, color
- **auth.users**: Supabase 기본 인증 (이메일/비번)

## 8. 로드맵 (앞으로 하면 좋은 것)
- **네이티브 앱 전환(EAS)** → 스토어 등록 + **안정적 네이티브 푸시**(현재 알림 문제 해결)
- 미장 차트 프록시 추가
- 웹에서 안 되는 로컬알림 토글 정리 (Web Push로 일원화)
- 온보딩·디자인 완성도
- (아이디어) 패턴 분석·세력 감지 고도화 등

## 9. 알아둘 제약/이슈
- iOS PWA 푸시는 네이티브보다 불안정 → 네이티브 전환 시 해결
- 미국 주식 차트 CORS 미해결
- Vercel 무료 크론 제약 (lazy 수집으로 보완 중)
- 설정의 로컬알림 토글은 웹에서 무동작
